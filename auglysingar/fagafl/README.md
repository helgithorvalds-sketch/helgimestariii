# Fagafl auglýsing

`Fagafl_lokautgafa_2` (PNG 2160×2160, JPG, PDF) er útgáfan eftir athugasemdir Sigurðar 6. nóv. 2026.

## Hvað breyttist

- „Reykjavíkurborg og Garðabær“ varð „Reykjavíkurborg og húsfélög“.
- Ný lína: „Við sjáum um smíði, múrvinnu og allt sem viðkemur viðhaldi og nýbyggingum.“

## Hvað er ekki auglýst (eitt fyrirtæki í hverjum flokki í SVIF-bæklingnum)

| Þjónusta | Flokkurinn er hjá |
| --- | --- |
| Málun | Litamálun |
| Pípulagnir | HK Lagnir, MS Lagnir |
| Rafvirkjun | RÓM Verk |
| Gluggaskipti | Gluggavinir, TME Gluggar |
| Flotun | Heit gólf |
| Múrbrot og steinsögun | Steindi |

## Endurgera

Frumskráin er `src/fagafl.html` (letur og myndir fylgja í `src/`).

```bash
node auglysingar/fagafl/src/render.mjs
```
