- Myth question the viewer already has: "If planes are metal and way up high, why don't they get struck?" → test → "they DO, ~1 per plane per year" → why safe (Faraday cage) → link back to everyday (spoon between finger and doorknob).

## Learning science
- Curiosity gap (Loewenstein 1994); curiosity boosts memory for answer (Kang 2009) and incidental info (Gruber 2014).
- Predict-before-reveal: passive demo ≈ no demo; predicting improves understanding (Crouch 2004); surprise tracks learning (Brod 2018).
- Misconception refutation videos beat clear explanations, d≈0.8 (Muller 2008).
- Stories "psychologically privileged" — 4 Cs: causality, conflict, complications, character (Willingham 2004).
- Mayer: segmenting, signaling, coherence, voice, personalization (conversational "you" beats formal).
- Seductive details hurt learning (Harp & Mayer 1998; Rey 2012) → jokes must carry the concept.
- Dual coding (Clark & Paivio 1991); concreteness fading (Fyfe 2014); analogies need explicit mapping (Richland & Simms 2015).
- Perspective comparisons for big numbers improve recall (Barrio 2016).
- Prior knowledge (How People Learn); emotion strengthens memory (Tyng 2017).
- Engagement drops after ~6 min; enthusiasm helps (Guo 2014).

## Checklist per 60–120 s segment
1. Concrete, high-stakes sentence one.
2. Confirm promise in 3 s, open one loop.
3. A villain / a reason to care.
4. Ask the question/myth the viewer already has.
5. Get a prediction before the reveal.
6. Anchor abstract ideas in something they've touched.
7. One idea per segment: name it, one analogy, show it once.
8. Number → familiar comparison.
9. Spell out the analogy's mapping.
10. Show it physically, not only in narration.
11. Concept arrives as the fix after a failure (but → therefore).
12. Failure shown honestly, as data.
13. Link beats with "but"/"therefore", never "and then".
14. Hold one thing back.
15. Jokes carry the concept.
16. Signal the key line (music drop / slow down).
17. Talk like a person, real excitement.
18. Name your characters.
19. End on a callback to the opening promise.
20. Write the hook last.
